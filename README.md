# AI-python-GUI-game

## racing-championship

A browser-based story-mode racing game (HTML/CSS/JS, no build step). Play as Charles Dumont
of Falcon Racing through a 5-race championship (Sepang, Singapore, Monza, Spa, Silverstone),
making tire, pit-stop, safety-car, and overtake decisions through a lap-by-lap simulation with
track-specific weather and degradation modeling.

To play: open `racing-championship/index.html` in a browser.
